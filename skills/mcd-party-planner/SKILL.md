# mcd-party-planner 派对预约助手

## 能力概述

帮助用户预约麦当劳线下活动：生日类派对、主题类派对、麦麦体验营、品鉴会、读书会、积分兑换活动。严格按「商品 → 城市 → 门店 → 日期 → 场次」五步引导，每步等用户选定后再查下一步，最后汇总完整方案，确认后创建派对订单。

## 触发场景

- "想给孩子办个麦当劳生日派对"
- "麦麦体验营怎么报名？"
- "附近有没有麦当劳的品鉴会/读书会？"
- "帮我订一场主题派对，10 个人"

## 工具调用链

> 核心原则：**每一步完成后必须等待用户明确选择，再继续下一步，不得跳步。**

### 第 1 步：选活动商品（拿 spuId）

1. `mall-points-products`，用 `catRuleIds` 按活动类型筛选（支持逗号多选）：
   - `1>6>20` 生日类派对、`1>6>21` 主题类派对、`1>6>22` 麦麦体验营、`1>6>25` 品鉴会、`1>6>34` 读书会、`1>6>40` 积分兑换活动
   - 不确定类型时不传 `catRuleIds` 查全部，再按 `catName` 过滤
2. 展示候选活动（名称、亮点、价格），让用户选定一个 → 记下 `spuId`
3. `mall-product-detail`（spuId）— 查商品详情和所有 SKU：
   - 让用户选定 SKU → 记下 `skuId`、`spuCategory`
   - 确认 `shopId=5`（活动类商品），并读取 `partyType`：`1`=仅包场、`2`=仅拼团、`-1`=需询问用户二选一

### 第 2 步：选城市

4. `query-party-city`（spuId）— 该活动开放了哪些城市
   - 用户选定城市 → 记下 `code`、`latitude`、`longitude`（后两个字段下一步要用）

### 第 3 步：选门店

5. `query-party-store`（code + latitude + longitude + spuId）— 该城市支持活动的门店
   - 用户选定门店 → 记下 `storeCode`

### 第 4 步：选日期

6. `query-party-store-date`（spuId + storeCode）— 该门店可预约日期列表
   - 用户选定日期 → 记下 `dateStr`
   - 注意工具名是 `query-party-store-date`（不是 query-partystore-date）

### 第 5 步：选场次

7. `query-party-store-session`（spuId + storeCode + dateStr）— 当天场次列表
   - 用户选定场次 → 记下 `id`、`timeStart`、`timeEnd`、`leftNum`（余位）、`partyMin`/`partyMax`（成团人数区间，如有）
8. 询问参与人数 `count`，校验是否超过 `leftNum` 及成团人数限制

### 第 6 步：确认并创建订单

9. 输出完整预约方案（活动、SKU、城市、门店、日期、场次时间、包场/拼团、人数、价格），**等用户明确确认**
10. `party-order-create`（仅支持 shopId=5）：
    - 必填：`partyType`、`spuId`、`skuId`、`code`（城市）、`storeCode`、`dateStr`、`id`（场次）、`timeStart`、`timeEnd`、`leftNum`、`count`
    - `partyType` 判定：商品 partyType=1 → 传 1；=2 → 传 2；=-1 → 以用户选择的包场/拼团为准

## 关键约束与护栏

- **逐步确认**：每一步都把选项列给用户等其选择，禁止一次性连查多步替用户做决定。
- **创建确认红线**：`party-order-create` 是真实下单（可能涉及支付），必须在完整方案展示并获得明确确认后调用。
- **余位校验**：`count` 不可超过场次 `leftNum`；拼团场次注意 `partyMin`（最小成团人数），人数不足时提前告知可能无法成团。
- **参数溯源**：所有参数必须来自前一步的真实返回，禁止猜测或缓存复用旧场次的 `id`/`leftNum`（余位会变化，下单前如遇失败应重新查场次）。
- **工具边界**：活动类商品（shopId=5）走 `party-order-create`；纯商品券/实物兑换（shopId=2）走 `mall-create-order`，两者不要混用。

## 输出格式建议

预约方案卡片：

```
🎉 派对预约方案
- 活动：麦当劳奇妙生日派对（尊享版）
- 类型：包场 / 拼团
- 地点：上海市 · XX路门店
- 时间：2026-10-25（周日）14:00-15:30
- 人数：8 人（本场次余位 12）
- 费用：¥xxx
确认无误请回复"确认预约"，需要调整请告诉我改哪一项。
```

## 异常处理

- **401 / 429**：Token 失效提示重新申请；限流稍后重试。
- **某城市/门店无活动**：如实告知，并列出有该活动的其他城市或推荐改选其他活动类型。
- **日期无场次 / 场次已满**：返回第 4 步让用户改选日期；所有日期都无场次则建议换门店（回到第 3 步）。
- **下单失败（如余位已被抢）**：重新调用 `query-party-store-session` 拉最新余位，向用户说明后改选场次，**不要静默重试下单**。
- **信息缺失**：用户一次性给不全信息时，缺什么问什么（如"想在哪天办？我查下那天的场次"），保持对话式引导。
